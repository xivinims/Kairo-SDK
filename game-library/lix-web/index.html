LIX ORIGINAL · PT-BR · BOXEDWINE

Lix no navegador

Abre o Lix 0.10.36 oficial dentro do navegador usando Wine + WebAssembly. A tradução brasileira é aplicada em memória antes de iniciar o jogo.

Clique em “Jogar Lix agora”. Na primeira abertura o navegador precisa baixar o runtime Wine e o jogo.
O Lix vai aparecer aqui.
Depois que abrir, clique dentro da tela para usar teclado e mouse.
Detalhes técnicos


Primeira execução pode transferir dezenas de MB. O runtime BoxedWine/Wine é open source. Lix é o jogo original de SimonN/LixD, com a localização PT-BR aplicada no navegador.
